# 🎓 Enrollease – Course Enrollment System

Enrollease is a web-based **Course Enrollment Management System** developed using **Java and Spring Boot**. The application allows students to view available courses, register/login, enroll in courses, and manage their enrollment details.

## 🚀 Project Overview

The main goal of Enrollease is to simplify the course enrollment process by providing a centralized system for managing student and course information.

The project demonstrates practical implementation of **Spring Boot MVC, Spring Data JPA, MySQL, JSP, validation, authentication, and CRUD operations**.

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/sameerahire674-png/Enrollease-Course-Enrollment-System.git
```

### 2. Open the project

Open the project in:

* IntelliJ IDEA
* Spring Tool Suite
* Eclipse

### 3. Configure MySQL

Create a database in MySQL and update the database configuration in the project's properties file.

### 4. Build the project

```bash
mvn clean install
```

### 5. Run the application

Run the Spring Boot application from the main application class.
